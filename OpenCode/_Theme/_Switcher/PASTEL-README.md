# OpenCode 浅色壁纸与黑字主题

已应用至本机 OpenCode Desktop 1.18.29。使用用户提供的 PNG 原图，界面正文、辅助文字、链接、输入文字、按钮文字为纯黑色 `#000000`，配合奶油白半透明面板和淡紫色按钮。

背景采用 cover 居中显示，叠加 50%–54% 浅色遮罩。原图逐像素计算的黑字最低对比度为 5.994:1，按钮各状态为 7.986:1 以上。代码语法和状态保留颜色区分；终端沿用自身渲染器主题。

原图 SHA256 保持不变。仅替换已有主题 CSS 并新增 PNG 背景，其他 6,992 个归档条目的字节及元数据保持一致。Electron 原生读取验证通过。尚未检查实际桌面渲染效果，请重新打开 OpenCode 查看，如需微调可发送截图。

## 恢复到上一版暖金主题

保存任务并完全退出 OpenCode 后执行：

```powershell
node "pastel-tool.cjs" restore
```

恢复时检查进程和资源哈希；应用已更新或被另行修改时拒绝覆盖。恢复后原有暖金主题恢复入口可继续使用。最初原版备份仍保留。

这是非官方本地资源定制，软件更新可能覆盖，不能将旧包覆盖到新版本。当前应用与备份记录见 `pastel-v2-manifest.json`；`pastel-manifest.json` 是未应用的初次候选包记录。
