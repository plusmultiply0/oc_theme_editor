# 演示脚本（60–90 秒）

> 在没有真实画面之前，不得剪出暗示已成功应用成片，也不得用合成画面冒充真实效果。

## 分镜

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0–8s | 原始 OpenCode 界面 → 打开本工具 | 官方主题只管颜色，不管背景图，所以只能做本地资源定制 |
| 8–20s | 拖入一张图片 → 自动取色完成 | 原图不动、不上传；取色是确定性的，同一张图结果一致 |
| 20–35s | 拖动遮罩/面板/模糊滑杆 → 右侧对比度逐条变化 | 对比度按「图片→遮罩→面板」三层合成后的实际底色算，不是拿两个色值比 |
| 35–50s | 点「应用到 OpenCode」→ 确认框（安装位置/版本/3 个条目/备份位置/风险） | 两次确认；写入前备份，写入后 hash 复核 |
| 50–70s | 关闭并重新打开 OpenCode → 侧栏、正文、代码、输入、菜单、diff | 终端与语法高亮不改，这是刻意的 |
| 70–85s | 回到工具 → 「恢复」→ 恢复上一主题 → 回到原版 | 恢复是新的前向操作，不是撤销历史 |
| 85–90s | 结尾卡 | 已验证版本 1.18.29；非官方定制，更新后需重新应用 |

## 拍摄前必须完成

1. T63 真实安装验收（需 jc 明确授权）：应用 → 重启观察 → 换主题 → 恢复，记录版本与关键区域截图。
2. T64 走查：侧栏、正文、代码、输入、菜单、按钮状态、终端、错误/diff，以及背景缩放与窗口变化。
3. 每个写入阶段仍要重新预检（进程、写权限、磁盘）。
