# 便携包干净环境验证清单（T65）

> 我在开发环境里**无法启动 Electron 窗口**（`ELECTRON_RUN_AS_NODE` 导致主进程不起；去掉后 GUI 进程 stdout 不回传），
> 所以这一步只能由 jc 在一台「干净」的机器上执行。下面是逐条可勾选的步骤。

## 准备

1. 把 `release2/win-unpacked` 整个目录复制到目标机器（U 盘、另一台电脑、或本机另一个盘符根目录下的临时文件夹）。
   本轮产物在 `release2/`——上一轮的 `release/` 因 `app.asar` 被占用没能删掉，是旧代码，**别拿去测**。
2. 确认目标机器**没有** Node、Python 的全局安装参与：即不要在项目目录里用 `npm start` 启动，直接双击目录里的
   `OpenCodeThemeSwitcher.exe`。
3. 目标机器上应已安装 OpenCode 1.18.29（否则预期结果就是「未发现目标」，这本身也是一条有效验证）。

## 逐条勾选

- [ ] **能启动**：双击 `OpenCodeThemeSwitcher.exe` 后出现窗口，无报错弹窗。
- [ ] **无命令行依赖**：确认没有手动设置 PATH，也没有开终端。
- [ ] **目标识别**：顶栏显示 `supported` 与 `1.18.29`，并列出安装路径。
- [ ] **选图**：点「选择图片」能弹出系统文件框；拖一张 PNG/JPG 进虚线框也能导入。
- [ ] **缩略图与取色**：左上方出现缩略图，右侧「可读性检查」出现逐条对比度。
- [ ] **预览**：中间模拟预览随参数变化，显示「模拟预览，真实效果取决于已验证版本」。
- [ ] **参数**：遮罩 / 面板 / 模糊滑杆、明暗模式、主色、重置参数都生效。
- [ ] **缩放**：点 100% / 125% / 150%，三档下布局都不裁切、不横向溢出。
- [ ] **减少透明度**：勾选后面板变纯色。
- [ ] **外链**：点预览里的「对比度标准」会用系统浏览器打开 w3.org（https 白名单生效）。
- [ ] **应用**：点「应用到 OpenCode」→ 确认框显示安装位置、版本、3 个条目、备份位置、需要空间 → 确认 → 成功。
- [ ] **权限与磁盘**：若目标正在运行，应被拒绝并给出中文提示（可选验证）。
- [ ] **恢复**：右侧「恢复」列出「上一主题」与「原版」及创建时间；两个入口各点一次，均成功。
- [ ] **运行数据位置**：确认备份与日志写在 `%LOCALAPPDATA%\OpenCodeThemeSwitcher\`，而不是便携包目录里。
- [ ] **卸载不留痕**：删掉整个 `win-unpacked` 目录后，运行数据目录仍然存在（这是刻意的：恢复能力不随程序删除而消失）。

## 判失败的情形（请记录具体提示）

- 启动时报缺 DLL、缺模块、白屏。
- 目标识别为空（但目标机器确实装了 1.18.29）。
- 应用时报权限 / 磁盘 / 进程相关错误且提示不可理解。
- 三档缩放下出现横向滚动条或内容被截断。
- 备份或日志被写进便携包目录（说明路径解析依赖了程序所在目录，属于缺陷）。
