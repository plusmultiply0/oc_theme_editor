# 安全边界与威胁模型

这份文档写的是「工具保证什么、不保证什么」，以及每条保证落在哪个文件里。

## 1. 信任边界

```
renderer（React，沙箱，无 Node）
   │  contextBridge 白名单，只传 ID 与参数对象
   ▼
preload（只转发已声明的方法）
   │  ipcMain.handle，入参用 zod 复验
   ▼
主进程服务层（唯一持有真实路径的一层）
   │
   ▼
core（主题生成 / 归档补丁 / 事务）
```

- renderer 拿不到任何路径：图片只给 `imageId`，预览给的是工具自己生成的缩略图 data URL。
- 拖拽导入传的是 `Uint8Array` 文件内容，不是 `File.path`——即便 Electron 提供了路径也不用。
- 所有跨边界参数在主进程用 `src/shared/schema.ts` 的 zod schema 复验。

## 2. 写入范围

| 层 | 允许 | 不允许 |
|---|---|---|
| 应用归档内 | 3 个白名单条目：`out/renderer/index.html`、`out/renderer/oc-theme-custom.css`、`out/renderer/oc-theme-background.jpg` | 其他任何条目；可执行文件；安全开关 |
| 运行数据目录 | `%LOCALAPPDATA%\OpenCodeThemeSwitcher\`（备份、事务日志、准备记录、缩略图、导入副本） | 写进源码目录、写进用户 OpenCode 配置目录 |
| 原图 | 只读 | 不写回、不移动、不删除 |

白名单写在 adapter 声明里（`src/adapters/opencode-desktop.ts` 的 `allowedChanges`），
准备区生成后逐条目核对；不在白名单内的变更直接判失败。

## 3. 事务安全

- **两段式**：`stageTheme` 只准备（不改安装），`applyTheme(operationId)` 才写入。界面不能传路径，只能传 operationId。
- **提交前失败** → 落 `failed`，安装原封不动。
- **提交后无法自证** → 落 `needs_recovery`，**绝不盲目回滚**（回滚可能覆盖掉已经成功的新状态）。由用户通过恢复入口决定。
- **同卷 rename**：准备好的归档先写到目标同目录的临时文件，再 `rename` 覆盖，避免出现半截文件。
- **hash 复核**：准备时刻记下 `beforeHash`，提交前再读一次，不一致就拒绝（`TARGET_HASH_MISMATCH`）。
- **并发**：实例独占锁（文件 `wx` 创建）+ 进程内 in-flight 集合，双击不会开出第二个事务。
- **unpacked 条目**：重打包必须保留 47 个原生模块的 unpacked 标记，否则应用启动即崩（见 `docs/architecture.md`）。

## 4. 备份语义

| 类型 | 含义 | 约束 |
|---|---|---|
| original | 首次接管时的状态 | 首次接管即发现目标已被改过 → `pristine=false` 并**禁用恢复原版** |
| previous | 上次成功应用前的状态 | 只保留最近 3 份 |
| pre-restore | 执行恢复前的现场 | 保证恢复失败也不会把用户推到更糟的状态 |

备份一律复制后重算 SHA256，不符即删坏备份并报错——**不留假备份**。

## 5. 输入安全

- 图片：magic bytes 判定格式，不只信扩展名；SVG 明确拒绝；20 MiB / 40 MP 上限；原图只读。
- CSS 注入：背景图片引用必须满足 `validateImageRef()` —— 拒绝 `http(s)://`、`//`、`file:`、绝对路径、
  含 `;'"` 与换行的注入串、`@import`。
- 不生成 `* { ... !important }` 这类全局覆盖；终端与语法高亮不在覆盖范围内。
- 外链：只放行 `https://`，由主进程 `shell.openExternal` 打开。

## 6. 隐私

- 不联网：无遥测、无更新检查、无埋点。
- 图片不出本机：分析在本进程用 sharp 解码，不上传。
- 运行数据只落本机用户数据目录。
- `npm run audit`（`tools/audit.cjs`）会检查源码与文档里是否混入作者专属绝对路径、用户名、密钥形态，
  以及产物里是否混入归档/备份/个人图片。

## 7. 不保证什么

- **不保证兼容所有版本**：只认已验证版本白名单，其他版本只允许预览。
- **不保证视觉一致**：预览是模拟的，真实效果以实际渲染为准；未做真实界面像素采样，因此不宣称无障碍合规。
- **不保证能撤销一切**：如果备份目录被手动清理，或应用被升级后强行恢复，工具会拒绝而不是「尽力而为」。
- **不绕过防护**：遇到签名校验、文件占用、权限不足，只上报，不绕过、不提权、不结束进程。
- **未做**：反篡改校验（不校验目标归档的数字签名）、多用户隔离（按当前用户数据目录存放）。
