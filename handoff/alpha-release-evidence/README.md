# Alpha 发布证据目录（私有，不入库）

这里存放 Alpha 候选版本的**原始证据**：测试日志、SHA256 清单、真实截图、
DOM 探针输出、机器与版本信息。

**为什么单独建目录**：这些材料里必然含本机绝对路径、用户名、安装位置、
事故现场信息。公开版本只保留**去标识后的摘要**（写进 `docs/alpha-acceptance.md`），
原始证据留在本机。

## 当前状态

建立于 2026-09-12（A0）。内容尚未入库：本目录除 `README.md` 外全部被
`handoff/alpha-release-evidence/.gitignore` 忽略。

## 约定

- 文件名带时间戳，避免覆盖历史：`2026-09-12T1930-a4-gate.txt`
- 每份证据的**摘要**（命令、退出码、测试数、结论、证据文件名）写进
  `docs/alpha-acceptance.md` 的对应条目；原始文件只留在这里。
- 不往这里放：用户私人壁纸、聊天内容、完整用户目录列表。
- 候选包一旦冻结，其 SHA256 清单记入 `docs/alpha-acceptance.md`；
  包有任何改动都必须重算并重跑受影响项。
