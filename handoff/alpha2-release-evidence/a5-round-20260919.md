## 3. P2 缺陷登记：输入框占位文字不可读（jc 附真机截图，不阻塞本轮）

- **现象**：C 主题（浅色）下聊天输入框 placeholder 文字极淡，jc 报「输入框文字看不清」。
- **根因（只读诊断）**：官方样式预置 `::placeholder { color: color-mix(in oklab, currentcolor 50%, transparent) }`；
  我们映射的 `--text-weak/--text-weaker/--v2-text-text-faint` = `#585e63`（原对比度 5.37:1 达标），
  被官方 50% 混色后落在输入框底 `rgba(228,233,236,0.86)` 上有效对比度仅 **2.07:1**。
  正文输入色 `--text-base #141922` 不受影响；别名链（`--color-text-weak: var(--text-weak)`）完好。
- **定性**：**非 alpha.2 回归**——`src/core/theme` 自 alpha.1 未改动，09-18 轮整体回执漏查该项。
- **处置**：jc 裁定「不阻塞，按实际回执登记其余项」。修复属 token 推导策略
  （placeholder 类色需按官方 50% alpha 预暗化），**不进已登记候选**，立后续修复轮。
