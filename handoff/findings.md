# 已知事实与待核实事项

## 已核实：现有原型

来源：2026-09-10 只读检查源目录 README.md、pastel-tool.cjs、build-pastel.py、task_plan.md、progress.md。

- 源目录：原型所在目录（绝对路径已脱敏）。
- 包含雪景、明日方舟暖色、粉彩三套 CSS/脚本及配色、项目说明。
- 文档明确原型针对本机 OpenCode Desktop 1.18.29，并使用本地资源补丁，而非已确认的官方桌面换肤接口。
- `pastel-tool.cjs` 写死安装目录、原始图片路径、版本、当前归档 SHA256，并依赖旧 manifest 和个人 skill 下的 `asar_stage.cjs`。
- `pastel-tool.cjs` 包含 stage/apply/restore、进程检查、备份与哈希检查；其 restore 返回之前的明日方舟主题，不等同于恢复未定制原版。
- `build-pastel.py` 通过字符串替换生成 CSS/脚本，并写死本机图片路径；不适合作为通用主题生成器直接发布。
- 已有历史日志声称完成归档条目和 Electron 读取验证；这是历史证据，本轮未重跑，不能证明任意安装可用。
- 已有说明明确实际桌面视觉检查尚有待人工确认；不得把归档可读当成视觉验收。
- 上轮复制的 16 个文件不包含 ASAR 依赖实现、实际背景图片、备份和部署 manifest，不能视为独立可执行交付。
