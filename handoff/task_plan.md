# OpenCode Theme Switcher：第一版执行计划

状态：计划编制完成；产品开发尚未启动。

## 目标与边界

将本机专用换肤原型改造成可交付的 Windows 桌面工具，完成「选择图片 → 自动配色 → 调整可读性 → 预览 → 应用与恢复」闭环。

- 本轮只编制交接计划，不执行原型脚本、不安装依赖、不修改 OpenCode。
- 新开发仅在用户确认的项目目录内进行。原型保留，不直接覆盖；安装资源写入另设真人确认。
- 不开发账号系统、主题商城、云端图片处理、AI 生图、自动更新、macOS/Linux 适配、任意 CSS/JS 注入、终端主题重写。
- 五项功能的详细任务、接口和验收要求见 `EXECUTION_PLAN.md`。

## 决策

- 安全适配是最先验证的风险，不先画完界面再判断能否应用。
- 优先使用经核实的官方扩展机制；资源补丁仅作为明确标注的受限兼容路线。
- 不把历史记录中的 1.18.29 认定为官方最新版，也不假定其他发行渠道具有相同结构。
- P2、P3、P4 可在 P1 的类型契约冻结后并行；P0、P1、P5、P6 必须按依赖执行。
- 旧的 `task_plan.md`、`progress.md` 属于历史换肤任务，不覆盖；本轮文档单独放在 `handoff/`。
- 用户再次明确目标位置后，交接文档发布到仓库内的 `handoff/`；不存在时创建，仅新增文档，不覆盖原型。
