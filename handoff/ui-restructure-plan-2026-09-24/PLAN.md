# 界面信息架构重整计划（2026-09-24）

> 来源：jc 五张截图反馈——
> 1. 「可读性检查」面板太长 → 移到选项卡或次要位置，只显示简略信息；
> 2. 「目标 / 待恢复」两个面板 → 调整布局与折叠显示；
> 3. 「恢复」面板 → 移到选项卡或次要位置，精简文字说明；
> 4. 顶栏 → 调整高度，启动按钮移到左下方，精简文字说明。
>
> 基线：HEAD `366612a`（alpha.5 已发布）。仅 renderer 改动，服务/协议/预览层零改动。

## 设计决定：右栏选项卡化 + 顶栏瘦身 + 启动按钮入状态栏

**核心判断**：主操作流（选图 → 参数 → 预览 → 应用）必须一屏可见；
诊断/恢复类信息（可读性明细、目标清单、恢复记录）是低频操作，全部归选项卡。
不做抽屉、不做弹窗——选项卡是最省交互成本且 e2e 最可控的重组方式。

```
现状三栏                              重整后
┌────────┬──────────┬──────────┐      ┌──────┬─────────────┬──────────┐
│图片参数│ 模拟预览  │可读性检查│      │图片参数│ 模拟预览     │[检查][恢复]│
│        │          │目标      │      │      │             │ 选项卡    │
│        │          │待恢复    │      └──────┴─────────────┴──────────┘
│        │          │恢复      │      ┌──────────────────────────────────┐
└────────┴──────────┴──────────┘      │状态栏：[启动 OpenCode] + 状态消息  │
顶栏：标题+启动按钮+长验证文字          顶栏：标题 + 紧凑目标芯片（一行）
```

## 任务分解（一项一提交）

### T1：顶栏瘦身 + 启动按钮移至状态栏（左下）

- 顶栏只留：标题「OpenCode 换肤助手」+ 副标一行 + **紧凑目标芯片**
  （徽章 + 版本号一行；installPath 与 rejectReason 改为一行省略号 + tooltip，
  不再展开成长段）；
- 「启动/打开 OpenCode」按钮从顶栏移除，改放**状态栏最左侧**
  （footer.status 内、状态消息之前），禁用态与文案逻辑不变；
- 顶栏 padding 与最小高度收紧，消除大片空白。

### T2：右栏选项卡骨架（检查 / 恢复）

- 右栏改为 tab 容器：`[检查][恢复]` 两个选项卡，默认「检查」；
- 「检查」选项卡 = 可读性面板（T3 改造）；
- 「恢复」选项卡 = 目标 / 待恢复 / 恢复 三块内容整体移入（T4 改造）；
- tab 状态仅存内存（不持久化），aria 语义（role=tablist/tab/tabpanel）。

### T3：可读性检查概要化

- 默认只显示**概要态**：结论行（全部达标 / N 项未达标）+ 代表性底色 +
  最差一项（名字 + 比值）；
- 明细列表（24 行）与三段长说明文字（范围/采样/verified）整体收进
  `<details>`「明细与判定依据」，默认折叠；
- 「全部条目达到目标值（估算）」保留为概要标题。

### T4：恢复选项卡内容重组 + 文案精简

- 三块内容顺序：目标 → 待恢复 → 恢复；
- 「目标」：按钮行保留（重新检测/选择安装目录），「已检查 N 个登记位置」
  维持现有 details 默认折叠；
- 「待恢复」：无未决操作时从整块面板压缩为**一行**（「没有未完成的操作」），
  有未决操作时展开成完整面板；
- 「恢复」：每条记录保留 名称/日期/适用版本/健康状态/按钮；
  两段橙色长说明（出厂指纹解释、接管快照解释）收进 `<details>`「说明」默认折叠，
  摘要化为一行（如「没有可证明的出厂原版 — 用首次接管快照」）。

### T5：测试适配与截图

- e2e 现有依赖（已核实）需同步改：
  - `panelWithHeading('恢复')` → 先切「恢复」选项卡再断言；
  - `.entries li` 明细断言 → 先展开 details 或改断言概要行；
  - `.target .muted`（installPath）→ tooltip 场景改为 title 属性断言；
  - `.side-column .panel` / `.topbar h1` / `.status` / `.controls .scope`
    / `.preview .mock-window` / `.preview-note` 尽量不动——结构兼容优先，
    能不改的测试一律不改；
- 单元测试（逻辑层）不受影响；真实窗口截图 before/after 对比留临时目录（不入库）。

**验收**：lint/typecheck 0；单测全绿；e2e 全绿；截图确认顶栏变矮、右栏只有选项卡。

## 边界（写死）

- 模拟预览层（mock-* / --p-*）与 token 一致性：零改动；
- 服务层、IPC 契约、应用/恢复行为逻辑：零改动（纯呈现层重组）；
- 选项卡化不得破坏 aria 语义与键盘可达性；
- 折叠默认态只影响**初始显示**，不得吞掉任何现有信息（明细仍可展开看到全部内容）。

## 时序

```
T1 ──→ T2 ──→ T3 ──→ T4 ──→ T5
```
T1 独立；T2 是 T3/T4 的容器；T5 收尾。全部本机可完成。
