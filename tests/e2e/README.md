# E2E（未实现，不要当成已通过）

`npm run test:e2e` 目前**没有任何用例**，脚本带 `--pass-with-no-tests`，退出码 0 只代表「没有用例」，不代表界面已被自动化验证。

## 为什么是空的

1. 开发环境里 `ELECTRON_RUN_AS_NODE=1`，此变量存在时 `require('electron')` 返回路径字符串，主进程根本不启动。
2. 去掉该变量后 Electron 以 GUI 子系统进程启动，stdout 不回传终端，无法判定窗口是否真的起来、按钮是否可点。
3. Playwright 对 Electron 的支持是实验性的，本项目尚未接入。

## 要补的话怎么做

1. 准备一个能在无头环境启动 Electron 的方式（例如 `xvfb` 或在有桌面会话的机器上手动跑）。
2. 用 Playwright 的 `_electron` / `electron.launch()` 起应用，断言五项功能闭环：
   - F1 选图与导入（含拖拽、格式错误、超限）
   - F2 配色与参数（滑杆、模式、主色、重置）
   - F3 预览与可读性（预览与生成同源、不合格时应用按钮禁用）
   - F4 应用与确认（确认框字段、双击不重复提交）
   - F5 恢复（原版 / 上一主题两个入口、失败提示）
3. 用例跑通前，验收报告里这一栏必须写「未执行」。
